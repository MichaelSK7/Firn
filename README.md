# Firn
___
*Another way to save information.*
Just give a source and destination path. When 'run' is clicked, a copy will be created or updated if copy already exists.

**Why?**
Imagine you play a lot of minecraft, and just for safety you would like to save/backup your world. Well i find it annoying to always go the the 'hidden' world folder, so i thought: "What if i can have a app that literally just saves from 1 path to the other.".
Thats it...

**Extras**
I also wanted to add some personal server capabilities — hard coded ofcourse. I could make it portable, but.. why? So there is a way to a folder in my server.
